# 🚌 Bus Ticket Booking System

A simple Java console-based Bus Ticket Booking System that allows users to view available seats, book tickets, cancel bookings, and manage passenger information.

The project demonstrates Java OOP concepts, `ArrayList`, methods, loops, and input validation.

## ✨ Features

* 💺 View available seats
* 🎫 Book bus tickets
* ❌ Cancel tickets
* 👤 Store passenger details
* 🔍 Search bookings by seat number
* 📋 View all bookings
* 🚫 Prevent double booking
* ✅ Validate seat numbers
* 💰 Fixed ticket price

## 🛠️ Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList
* Scanner
* Methods
* Loops
* Conditional Statements
* Switch Statement

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

```bash
cd bus-ticket-booking
```

### 3. Navigate to the source folder

```bash
cd src
```

### 4. Compile the Java files

```bash
javac Passenger.java BusTicketBooking.java
```

### 5. Run the application

```bash
java BusTicketBooking
```
